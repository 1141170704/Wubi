========================================
  CNB（cnb.cool）能不能打包这个 exe？
========================================

结论：能，但比 GitHub 绕。原因和方案都在下面。


========================================
一、先说清楚：CNB 没有 Windows 托管机
========================================

CNB 的官方托管构建节点是【按架构】划分的，不是按系统：

    cnb:arch:amd64        → Linux（x86_64）
    cnb:arch:arm64:v8     → Linux（ARM）
    cnb:arch:amd64:gpu    → Linux + GPU（16核/48G显存）

而 GitHub Actions 是【按系统】划分的，
有原生的 windows-latest，所以那边只要写一行：

    runs-on: windows-latest

CNB 没有这一档。这是两者最关键的差别。

CNB 官方也支持 Windows，但形式是【自托管构建机】：
需要你自己有一台 Windows 电脑，在
  根组织 / 组织设置 / 构建节点 → 新增 Runner
接入后通过
    runner:
      namespace: group
      tags: [windows]
来调度。
——可你本来就是因为没有 Windows 电脑才上云的，这就绕回去了。


========================================
二、所以 CNB 上走 Wine 路线
========================================

PyInstaller 官方 FAQ 明确写了这条路：

    "Can I package Windows binaries while running under Linux?
     No, this is not supported.
     Please use Wine for this, PyInstaller runs fine in Wine."

翻译：PyInstaller 本身不支持交叉编译，
但在 Linux 上装 Wine、在 Wine 里跑 Windows 版 Python + PyInstaller，
是可以产出 exe 的，官方认可这条路。

我已经把完整配置写好了：
    .cnb.yml

推到 CNB 仓库根目录，push 即自动触发，五个阶段：
    1/5 安装 Wine（winehq-stable）
    2/5 初始化 wineprefix
    3/5 装 Windows 版 Python 3.11.9（含 tkinter）
    4/5 装 PyInstaller → 打包 → 校验 dist/TianFuWubi.exe
    5/5 把 exe 推到仓库的 exe 分支（孤立分支，干净）

产物不用找 Artifacts，直接网页切到 exe 分支下载即可。
（CNB 的制品库主要面向 Docker/Helm/Maven/npm/Cargo，
  exe 这种通用二进制走 Release 或 git 分支更直接）


========================================
三、⚠️ 必须说实话：这个方案我没实测过
========================================

我这边是 Linux 沙盒，装不了 Wine，
也下载不到 Windows 版 Python（python.org 返回 403），
所以【我无法替你验证 Wine 路线一定成功】。

已知的风险点：
  · Wine 首次初始化偏慢
  · Windows Python 静默安装偶尔会卡
  · tkinter（Tcl/Tk）在 Wine 下依赖 DLL，可能需要 winetricks 补
  · 整体耗时会比 GitHub 原生 Windows 机长，预计 10–25 分钟

如果第 3 步报 tkinter 相关错误，
在装完 Python 后加一句：

    winetricks vcrun2019 corefonts

再重试。

免费额度够用：CNB 社区版 160 核时/月，
8 核跑 20 分钟 ≈ 2.7 核时，跑几十次没问题。


========================================
四、三种方案怎么选
========================================

┌──────────────┬──────────┬────────┬──────────────┐
│ 方案         │ 成功率   │ 麻烦度 │ 适合谁       │
├──────────────┼──────────┼────────┼──────────────┤
│ 云电脑       │ ★★★★★   │ 低     │ 想要一次搞定 │
│ GitHub       │ ★★★★★   │ 低     │ 能顺畅访问   │
│ CNB + Wine   │ ★★★☆☆   │ 中     │ GitHub 访问慢│
└──────────────┴──────────┴────────┴──────────────┘

【云电脑】——最省事，一定能成
    ToDesk 远控 / 阿里云无影云电脑 / 青椒云 / 顺网云
    按需开一台 Windows 云主机（几块钱一小时，很多有免费试用）
    远程进去 → 解压工程 → 双击 build.bat → 拿到 exe
    优点：和在自己电脑上操作一模一样，零不确定性
    缺点：要花点小钱，要装个远控 App

【GitHub Actions】——最稳，免费
    工程里 .github/workflows/build-windows.yml 已配好
    原生 Windows 托管机，3 分钟出结果
    缺点：国内访问有时不稳，需要能打开 github.com

【CNB + Wine】——国内快，但要多试
    就是本文件说的方案，.cnb.yml 已配好
    优点：国内访问流畅，腾讯自家产品
    缺点：未经实测，可能要调试一两次


========================================
五、CNB 的操作步骤（如果要用）
========================================

1. 打开 https://cnb.cool ，微信扫码登录（国内手机号即可，
   不用绑卡）

2. 新建仓库，把工程里这些文件传上去：
   --------------------------------
   .cnb.yml                    ← 打包配置（必须）
   main.py
   engine.py  db.py  config.py
   sounds.py  winapi.py
   ui_keyboard.py
   ui_phrase.py
   ui_settings.py
   selftest.py
   TianFuWubi.spec             ← 打包脚本（必须）
   assets/wubi86.txt           ← 词库（必须，没它打不出字）
   --------------------------------
   注意 .cnb.yml 前面有个点，是隐藏文件，
   手机文件管理要在设置里打开"显示隐藏文件"才能选中。

3. push 之后自动开始构建，在仓库页面点
   "构建" / "流水线" 看进度和日志。

4. 成功的话，切到 exe 分支，
   点 TianFuWubi.exe 下载。
