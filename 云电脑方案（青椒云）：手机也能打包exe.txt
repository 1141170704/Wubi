========================================
  云电脑方案（青椒云）——手机也能出 exe
========================================

这条路的思路：租一台 Windows 云电脑，用手机远程操控它，
在里面跑 build.bat，拿到 exe 再传回手机。
和你坐在自己电脑前操作一模一样，成功率最高。


========================================
零、先算一笔账（重要，先看这个）
========================================

青椒云按【开机时间】计费，关机就停。
CPU办公-标准版（4核8G）约 0.12 元/小时起。

打包一次大概需要开机多久？

    上传工程文件（走网盘，不开机，不计费）
    开机 ~1-2 分钟
    装 Python ~3-5 分钟
    装 PyInstaller ~2-3 分钟
    打包 ~3-8 分钟
    回传 exe ~1-2 分钟
    --------------------------------
    合计开机约 10-20 分钟 ≈ 几毛钱

【关于免费试用】
青椒云给"未付费使用过的新用户"提供 30 分钟免费试用
（RTX3090/4090 是 20 分钟）。

30 分钟【理论上够，但没有余量】。
一旦中间卡住（比如下载慢、报错要重来），时间就过了。
所以我的建议是：

    先充 10 元。
    按 0.12 元/小时算，10 元能开 80 多个小时，
    打包这种小事根本花不完，但换来了从容。

充 10 元还有个好处：不用抢免费试用的名额和时限，
失败了可以慢慢重试。

（价格以青椒云官网实时公示为准，我这里只是量级参考）


========================================
一、准备（不开机，不花钱）
========================================

1. 手机应用商店搜"青椒云"，下载安装
   （应用宝 / 小米 / 华为 / vivo / oppo 都有上架，
    认准开发者：深圳市瑞雨科技有限公司）

   官网：https://www.qingjiaocloud.com
   Android 需 5.0 以上，安装包约 76MB。

2. 手机号注册账号。

3. 【必须】完成实名认证
   个人中心 → 实名认证 → 个人认证
   需要：身份证正反面照片 + 人脸活体检测
   一般 1-5 分钟审核通过。
   --------------------------------
   不实名不能充值、不能开云桌面，这步绕不过去。
   --------------------------------

4. 注册完一般会发新人礼包，在个人中心看看有没有优惠券。


========================================
二、先把工程传上去（关键：不开机不计费）
========================================

青椒云自带"青椒云盘"，【上传文件不需要开机，不计费】。
这一步在手机上先做完，能省下宝贵的开机时间。

1. 打开青椒云 App → 底部/侧边找到【网盘】

2. 点【＋】→ 上传文件

3. 把这两个东西传上去：
       TianFu五笔Windows版.zip        （整个工程压缩包）
   （如果 App 不支持传文件夹，就传这个 zip，最省事）

4. 等上传完成。


========================================
三、开一台云电脑
========================================

1. App 里点【+ 添加云桌面】

2. 选配置。打包不需要显卡，选纯 CPU 的即可：

       CPU办公-标准版   4核 8G   —— 便宜，够用
       CPU办公-进阶版   8核16G   —— 我推荐这个，打包更快

   注意选【Windows】系统镜像（不要选 Ubuntu）。
   计费方式选【计时】。

3. 区域选离你最近的（华南/华东/华中…），延迟低。

4. 点【立即购买 / 立即添加】，然后【开机】。
   首次开机约 1-2 分钟。

   开机成功后点【进入桌面】，你会看到一个完整的
   Windows 桌面。到这一步，计费就开始了，动作快一点。


========================================
四、在云电脑里打包
========================================

【第 1 步】把工程文件拿进来

   桌面里双击【青椒云盘】图标 → 按提示添加
   → 打开"此电脑"，会出现一个 A 盘（或网盘盘符）
   → 里面就是你刚上传的 zip
   → 复制到桌面，右键解压

【第 2 步】装 Python（云电脑是新系统，没有 Python）

   打开 Edge 浏览器，访问：
       https://www.python.org/downloads/

   点大按钮下载最新版 Python。

   运行安装包时，【务必勾选最下面的】
       ☑ Add python.exe to PATH

   然后点 Install Now。

   --------------------------------
   嫌官网下载慢？可以用国内镜像：
       https://mirrors.huaweicloud.com/python/
   找对应版本的 python-3.x.x-amd64.exe 下载。
   --------------------------------

【第 3 步】确认 Python 装好了

   按 Win 键 → 输入 cmd → 回车
   在黑窗口里输入：
       python --version
   显示 Python 3.x.x 就成了。
   如果提示"不是内部或外部命令"，说明 PATH 没勾上，
   卸载重装一遍。

【第 4 步】双击 build.bat

   回到解压的文件夹，双击 build.bat。

   它会自动：装 PyInstaller → 语法自检 → 打包。
   等 1-3 分钟，看到这两行就成了：

       ============================================
         编译完成：TianFuWubi.exe
       ============================================

【第 5 步】把 exe 传回手机

   把 TianFuWubi.exe 复制到【青椒云盘】对应的盘里。
   然后回手机，打开青椒云 App 的【网盘】，就能下载了。

【第 6 步】关机（最重要的一步）

   用完一定要在 App 里点【关机】！
   只有关机才停止计费，断开连接不算关机。
   计时机超过 7 天不关机会被清理。


========================================
五、省时间小技巧
========================================

· 上传/下载都走网盘，不开机不计费，尽量在关机状态做完
· 开机前把要敲的命令在备忘录里写好，进去直接复制粘贴
· 打包成功后先关机，再慢慢从网盘下载 exe
· 如果想省事，可以一次多开几小时，把词库、
  Python、PyInstaller 都装好，之后重装系统就快了


========================================
六、常见问题
========================================

Q: 云电脑里没网 / 打不开网页？
A:  检查是否选了 Windows 镜像。实在不行联系青椒云客服
    （官网有在线客服和 400 电话）。

Q: Python 官网下载很慢？
A:  用华为云镜像 https://mirrors.huaweicloud.com/python/

Q: build.bat 报"未找到 python"？
A:  PATH 没勾。卸载 Python 重装，记得勾
    "Add python.exe to PATH"。

Q: 打包报红字？
A:  在文件夹里打开 cmd，输入
        python selftest.py
    看下哪一项失败，把结果告诉我。

Q: 免费试用的 30 分钟够吗？
A:  理论够，但没余量。建议充 10 元，从容很多。

Q: exe 杀毒软件报毒？
A:  PyInstaller 打包的 exe 被误报是常态，加白名单即可。
