========================================
  把文件转成手机能导入的 JSON（保留分组）
========================================

用 转APK导入.py 这个工具，双击运行，选文件，一键转换。
转出来的 json 传到手机，在短语管理里「导入」选它就行，
分组会原样保留。


========================================
三步走
========================================

第 1 步：双击 转APK导入.py
        （电脑上要有 Python；没图形界面的话看下面「命令行」）

        弹出窗口 → 点「选择文件」→ 选你要转的文件

第 2 步：点「开始转换」

        窗口下面会显示报告：总条数、分组数、
        每个分组各多少条。

第 3 步：生成的 json 在【原文件旁边】，名字是
        「原文件名_apk.json」

        把它传到手机（微信/QQ/USB 都行），
        在手机上打开 TianFu五笔 → 短语管理 →
        更多菜单 → 「导入 txt/JSON」→ 选这个 json。


========================================
支持哪些输入
========================================

1. PC 版 phrases.db
   最完整。连【分组顺序】和【空分组】都能带过去。
   位置：C:\Users\你的名字\AppData\Roaming\TianFuWubi\phrases.db

2. PC 版 / 手机端导出的 JSON 备份
   直接转，主要用于整理和校验。

3. 分节文本 txt
   格式是「#分组名」下面挂短语：

       #工作
       ggtt	五笔输入
       常用语一二三
       #生活
       买菜清单

   注意：编码和内容之间用【Tab 键】分隔。

4. CSV 表格
   表头写中文或英文都认，会自动识别：

       分组,编码,内容,权重
       工作,ggtt,五笔,100
       生活,,买菜,5

   分组列可以用 分号 / 顿号 / 斜杠 写多个：
   「工作;常用」→ 一条短语同时属于两个分组。

5. 五笔码表（wubi86.txt 这种）
   本身没有分组，工具会帮你自动分：
       · 编码首字母 → A部、B部…（25 组，默认）
       · 码长       → 一级简码 / 二级简码 / 三级简码 / 全码
       · 常用程度   → 常用 / 次常用 / 生僻
       · 不分       → 全部进「默认」


========================================
重要提醒
========================================

【1】8.6 万条全量码表，别一股脑导进短语库
    · 转出来的 json 有 13 MB
    · 手机上每条都会做成一行列表，8 万行会非常卡
    · 而且没意义：五笔打词是词库负责的，
      短语库只放你【自己常用的短语】
    建议：真要导码表，用命令行限制条数，比如只导 3000 条常用的：
        python 转APK导入.py wubi86.txt --max 3000

【2】导入是「追加」，不是「覆盖」
    手机端导入会把内容追加到现有短语后面，不会清空。
    想替换的话，先在手机上批量删除旧的，再导入。

【3】空分组
    手机端目前只能显示「有词条的分组」。
    纯粹的【空分组】在导入后不会显示（数据还在 json 里，
    下次编译新版 APK 就会恢复）。

【4】文件必须是 UTF-8 且【不带 BOM】
    工具已经处理好了。但如果你用记事本另存过，
    可能会加上 BOM，那样手机端会识别成普通文本，导入 0 条。


========================================
命令行用法（可选）
========================================

    python 转APK导入.py 输入文件 [输出.json] [选项]

选项：
    --mode=initial   按编码首字母分组（默认）
    --mode=len       按码长分组
    --mode=freq      按常用程度分组
    --mode=none      不分组
    --max 3000       只保留权重最高的 3000 条

例子：
    python 转APK导入.py phrases.db
    python 转APK导入.py 我的短语.csv
    python 转APK导入.py wubi86.txt --mode=len --max 5000


========================================
常见问题
========================================

Q: 双击 .py 没反应
A: 没装 Python，或者 .py 被关联成了记事本。
   在文件夹里打开 cmd，输入：
       python 转APK导入.py

Q: 转换出来 0 条
A: 看窗口里的报告。常见原因是 txt 用了空格而不是 Tab 分隔，
   或者 CSV 表头没被识别（改成「分组,编码,内容」试试）。

Q: 手机上导入后分组名不对
A: 检查源文件里的「#分组名」是不是太长（超过 16 字）
   或者含空格标点 —— 这种会被当成说明文字跳过。

Q: 想保留空分组和分组顺序
A: 需要用 PC 版 phrases.db 作为输入（它记录了这些信息），
   并且手机端要装【重新编译过的新版 APK】
   （Io.java 的 importJson 已加上读取 tagOrder / emptyTags）。
