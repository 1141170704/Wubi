========================================
  手机专用：用 GitHub 云端打包 exe
========================================

你没有 Windows 电脑，又想在荣耀 Magic8 这类手机上
拿到 TianFuWubi.exe，用这个办法。

全程用手机浏览器操作，不需要电脑，不需要敲命令。
大约需要 10 分钟，其中 3 分钟是等云端编译。


========================================
为什么手机不能直接编译
========================================

三道坎，任何一道都过不去：

1. CodeAssist 不认 Python
   你手机上那个 CodeAssist 只支持 Java / Kotlin / XML，
   是纯安卓开发用的 IDE。

2. 架构不对
   荣耀 Magic8 是骁龙 8 Elite Gen5，ARM 架构。
   而 Windows 的 exe 是 x86/x64 的 PE 格式。
   ARM 的手机永远产不出 x86 的 exe。

3. PyInstaller 不支持交叉编译
   官方 FAQ 原话：
   "Can I package Windows binaries while running
    under Linux? No, this is not supported."
   在哪个系统上打包，就只能产出哪个系统的程序。

所以换个思路：
让 GitHub 免费提供的【Windows 云主机】帮我们打包，
打完把 exe 传回来，手机上直接下载。


========================================
第 1 步：注册 GitHub 并新建仓库
========================================

1. 手机浏览器打开：
       https://github.com

2. 点右上角 Sign up 注册账号（免费）。
   用邮箱注册即可，验证一下邮箱。

3. 登录后，点右上角你的头像 → Your repositories
   或者直接在浏览器打开：
       https://github.com/new

4. 填写：
       Repository name（仓库名）：TianFuWubi
       下面选 Public（公开）
       勾选：☑ Add a README file

5. 点绿色的 "Create repository" 按钮。

   看到仓库页面就成功了。


========================================
第 2 步：上传文件（手机上就能传）
========================================

1. 在刚建好的仓库页面，点中间的蓝色文字：
       "uploading an existing file"
   （如果没看到，就点 "Add file" → "Upload files"）

2. 把整个 TianFuWubi_PC 文件夹【里面】的东西
   全部拖进上传框里。

   需要上传这些：
   --------------------------------
   main.py
   engine.py
   db.py
   config.py
   sounds.py
   winapi.py
   ui_keyboard.py
   ui_phrase.py
   ui_settings.py
   selftest.py
   TianFuWubi.spec
   build.bat
   运行.bat
   README.md
   assets\           （词库文件夹，必须传！）
   外置音色\          （可选）
   .github\workflows\ （打包配置，必须传！）
   --------------------------------

   --------------------------------
   手机上怎么拖：
   建议先在手机文件管理里把 zip 解压，
   然后用浏览器的"选择文件"逐个添加，
   或者用支持多文件的浏览器一次全选。

   如果 assets 文件夹传不上去，
   至少保证 assets/wubi86.txt 这个文件要传上去，
   它是五笔词库，没有它程序打不出字。
   --------------------------------

3. 拉到页面最下面，点绿色的
       "Commit changes"

   上传完成。


========================================
第 3 步：点一下按钮，云端开始编译
========================================

1. 在仓库页面顶部，点
       "Actions"
   标签页。

2. 如果提示 "I understand my workflows, go ahead and
   enable them"，点那个按钮启用。

3. 左侧列表里点
       "Build Windows exe"

4. 右侧会看到一个
       "Run workflow ▾"
   按钮，点它，再点弹出的绿色
       "Run workflow"

5. 等 2 到 3 分钟。
   页面会出现一条正在转圈的记录（黄色圆点）。

   变成【绿色对勾】就成功了。
   如果是【红色叉】，点进去看红色日志，
   把报错截图发给我。


========================================
第 4 步：下载 exe
========================================

1. 点那条变绿的记录。

2. 拉到页面最下面，找到
       "Artifacts"
   区域。

3. 点
       TianFuWubi-exe

   浏览器会下载一个 zip。

4. 解压这个 zip，里面就是
       TianFuWubi.exe

   这就是成品！


========================================
拿到 exe 之后
========================================

1. 把 exe 通过微信/QQ 传到电脑，或者用 U 盘复制。

2. 在 Windows 电脑上双击运行。

3. 按 Ctrl + 空格 呼出输入面板。

--------------------------------
注意：exe 只能在 Windows 电脑上运行，
手机上装不了也打不开，这是格式决定的。
你要在电脑上用它。
--------------------------------


========================================
常见问题
========================================

Q1: Actions 里看不到 "Build Windows exe"
A:  .github\workflows\build-windows.yml 没传上去。
    回第 2 步，确认这个文件夹也传了。
    注意 .github 是隐藏文件夹（前面有个点），
    手机文件管理可能默认不显示，
    需要在设置里打开"显示隐藏文件"。

Q2: 编译失败，日志有红字
A:  把红字截图发给我。
    常见原因是词库文件没传上去（assets/wubi86.txt）。

Q3: 改了代码想重新编译
A:  重新上传改动的文件，然后重复第 3 步即可。

Q4: 下载的 Artifact 在哪
A:  在 Actions → 那条记录 → 页面最下方 Artifacts 区。
    保留 30 天，过期要重新编译。

Q5: 不想用 GitHub，还有别的办法吗
A:  有：
    - 借一台 Windows 电脑，双击 build.bat（最简单）
    - 用云电脑服务（如 ToDesk 远控一台电脑、
      阿里云无影云电脑、青椒云），
      在云电脑里双击 build.bat
    - 找有电脑的朋友帮忙跑一下 build.bat
