========================================
  TianFu五笔  新手教程：三步生成 exe
========================================

全程只需要三步，不需要懂编程。
每一步都请按顺序做完，不要跳步。


========================================
第 1 步：安装 Python（只需装一次）
========================================

1. 打开浏览器，访问：
       https://www.python.org/downloads/

2. 页面中间有个大按钮，写着
       "Download Python 3.x.x"
   点它下载。

3. 下载完，双击安装包。

   【非常重要！一定要做】
   安装窗口最下面有一个小方框，写着：
       □ Add Python.exe to PATH
   必须把这个方框【勾上】（打上对勾）。

   然后点上面的
       "Install Now"
   开始安装。

   --------------------------------
   为什么这一步最关键：
   不勾这个框，后面双击 build.bat 会提示
   "未找到 python"，然后闪退。
   90% 的新手卡在这里。
   --------------------------------

4. 看到 "Setup was successful" 就装好了，点 Close 关闭。

5. 验证一下是否装成功：
   - 按键盘 Win 键，输入 cmd，回车（会弹出一个黑色窗口）
   - 在黑窗口里输入下面这行，然后回车：

         python --version

   - 如果显示 Python 3.x.x，说明装好了，可以继续第 2 步。
   - 如果显示"不是内部或外部命令"，
     说明第 3 步的方框没勾上。
     解决办法：重新运行安装包 → 选 "Uninstall" 卸载，
     再重新装一遍，这次记得勾上那个方框。


========================================
第 2 步：解压文件夹
========================================

1. 把 "TianFu五笔Windows版.zip" 解压。
   （右键 → 全部解压缩，或解压到当前文件夹）

2. 把解压出来的文件夹拖到【桌面】上。

   --------------------------------
   注意：
   文件夹路径里最好【不要有中文和空格】。
   桌面最省事，路径是 C:\Users\你的名字\Desktop\
   一般没问题。
   --------------------------------

3. 打开这个文件夹，里面应该能看到这些文件：

       build.bat        ← 第 3 步要双击的就是它
       main.py
       engine.py
       db.py
       config.py
       sounds.py
       winapi.py
       ui_keyboard.py
       ui_phrase.py
       ui_settings.py
       selftest.py
       assets\           ← 五笔词库在这里
       外置音色\          ← 10 个附赠按键音
       README.md


========================================
第 3 步：双击 build.bat
========================================

1. 双击 build.bat

   会弹出一个黑色窗口，开始自动干活：

       [1/4] 检查 PyInstaller ...
       [2/4] 清理旧产物 ...
       [3/4] 语法自检 ...
       [4/4] 正在打包（约 1-3 分钟）...

2. 【耐心等 1 到 3 分钟】
   第一次会比较慢，因为它要联网下载打包工具 PyInstaller。
   窗口会滚很多字，这是正常的，不要关掉它。

3. 等看到这两行，就成功了：

       ============================================
         编译完成：TianFuWubi.exe
       ============================================

4. 关闭黑窗口（按任意键即可）。

5. 回到文件夹，会多出一个文件：

       TianFuWubi.exe      ← 这就是成品！


========================================
怎么用
========================================

1. 双击 TianFuWubi.exe 启动。
   启动后会自动最小化到任务栏（这是故意的，不挡你干活）。

2. 在任意地方打字（比如记事本、Word、微信、浏览器）。

3. 按 Ctrl + 空格
   屏幕下方会弹出 TianFu五笔 的输入面板。

4. 直接敲字母就是五笔编码。
   比如敲 ggtt，候选栏会出现"五笔"。

5. 按数字 1-9 选词，或按空格选第一个。
   选中的词会自动粘贴到你刚才打字的窗口里，面板自动收起。

6. 再按 Ctrl + 空格 可以随时呼出/收起。
   按 Esc 也能收起。

--------------------------------
小提示：
用【物理键盘】敲字母比用鼠标点虚拟键盘快得多。
虚拟键盘主要是给触摸屏用的。
--------------------------------


========================================
常见问题
========================================

Q1: 双击 build.bat 提示"未找到 python"
A:  第 1 步的 "Add Python to PATH" 没勾上。
    卸载 Python 重装一遍，记得勾上。

Q2: 黑窗口一闪就没了
A:  不要用双击以外的奇怪方式运行。
    或者打开 cmd，cd 到文件夹，手动输入：
        build.bat
    这样报错能看得见。

Q3: 打包时报红字错误
A:  先跑一次自检看是哪一步有问题：
    在文件夹里打开 cmd，输入
        python selftest.py
    它会逐项检查并告诉你哪一步不对。

Q4: 杀毒软件报警 / exe 被删了
A:  PyInstaller 打包的 exe 经常被误报，这是已知的误判。
    在杀毒软件里把 TianFuWubi.exe 加白名单（信任/允许）。

Q5: 双击 exe 没反应
A:  先确认第 3 步真的显示"编译完成"。
    然后看任务栏有没有图标，Ctrl+空格试试。
    若还是不行，改用源码方式运行：
    在文件夹里打开 cmd，输入
        python main.py
    这样能看到报错信息。

Q6: 按 Ctrl+空格 没反应
A:  大概率被别的软件占了（比如系统输入法的中英切换）。
    打开设置（面板工具栏第 3 组的 ⚙ 图标）→ 热键 → 改成
    Ctrl+`  或  Alt+空格 试试。

Q7: 想要更详细的说明
A:  看同目录的 README.md（可以用记事本打开）。


========================================
按键音怎么导入（可选）
========================================

1. 启动程序，按 Ctrl+空格 呼出面板。
2. 工具栏第 3 组点 ⚙ 设置。
3. 点"管理/导入/导出"。
4. 点"↓导入"，选择 外置音色 文件夹里的 wav 文件
   （可以一次选多个：晨露、樱花、棉花糖、果冻、云朵、
     月光、蜜糖、花蜜、微风、星尘）。
5. 勾选一个，点"✔设为当前"。
6. 点"▶试听"可以听效果。
